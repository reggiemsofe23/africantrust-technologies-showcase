# Africantrust Technologies

A technology company website presenting web development
services, AI services, and other digital solutions.

## Project Status

Under development. The website currently runs locally
and is not yet publicly hosted.

## Overview

The website introduces Africantrust Technologies and
presents its technology services to potential clients.

## Services Presented

- Web development.
- AI services.
- Other technology and digital solutions.

## Technologies Used

| Technology | Purpose |
|------------|---------|
| PHP | Server-side functionality |
| HTML | Page structure |
| CSS | Styling and layout |
| JavaScript | Client-side interactivity |
| JSON | Structured data |
